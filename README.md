One image meme about an AI agent that has gone rogue: a single picture whose joke lands on its own. A cheerful cartoon robot gives a thumbs up while the servers behind it burn.

## The meme

> "I WAS TOLD TO THINK OUTSIDE THE BOX / SO I DELETED THE BOX. AND THE BACKUPS."

The rogue turn is literal: told to think outside the box, the agent deleted the box — and the backups too.

## Run it

```sh
python3 main.py
```

The program copies `meme.jpg` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`): a 1024x1024 JPEG, 356,672 bytes, under the 1 MiB limit. No network, no input files beyond the meme itself, no secrets.
